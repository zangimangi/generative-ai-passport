# 生成AIパスポート キーワード検索アプリ

React + TypeScript + Vite を使用した、生成AIパスポート試験向けキーワード検索アプリ。

GitHub Pages (`docs/`) に静的公開可能な構成。

---

# プロジェクト作成コマンド

## Vite + React + TypeScript プロジェクト作成

```bash
npm create vite@latest generative-ai-passport -- --template react-ts
```

---

## プロジェクトへ移動

```bash
cd generative-ai-passport
```

---

# パッケージインストール

## 基本パッケージ

```bash
npm install
```

---

## Tailwind CSS 関連

```bash
npm install -D tailwindcss postcss autoprefixer @tailwindcss/postcss
```

---

# 開発サーバ起動

```bash
npm run dev
```

---

# 本番ビルド

```bash
npm run build
```

---
